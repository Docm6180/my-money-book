# MyMoney V5.8 · 负债类别与还款页面调整版

更新：
1. 负债类别可以自行新增、保存、删除未被使用的自定义类别。
2. 负债管理内分为「新增负债 / 负债清单」和「新增还款记录 / 详细还款」两个独立页面。
3. 每笔负债的详细还款记录移到「新增还款记录 / 详细还款」页面。
4. 维持四种负债计算方式、43 个图标、旧账本数据与原本的 localStorage 键。
5. 自定义负债类别加入 JSON 备份和恢复。

部署：上传 index.html、upgrade-v5.html、sw.js 至 GitHub 仓库根目录。更新前先在旧版导出 JSON 备份。不要把私人备份上传公开 GitHub。
