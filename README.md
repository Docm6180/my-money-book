# 我的记账本 V5.6 — 仅 43 张新图标版

仅包含用户最新「图标.zip」对应的 43 个品牌图标。图标选择器仅列出这 43 项。旧账户或负债中已保存的其他图标路径不自动更改，删除旧图标后旧图片可能不显示，请重新选择。

## 安全更新顺序
1. 手机导出 JSON 备份并妥善保存，不要上传到公开 GitHub。
2. GitHub 的 brand-icons 文件夹中先删除旧图标（可以在 GitHub 网页逐个删除；大量文件更适合使用 Git 工具）。不要删除仓库或程序文件。
3. 在 brand-icons 文件夹内部上传本包 brand-icons 内全部 43 张 .webp。
4. 回到仓库根目录，上传 index.html、upgrade-v5.html、sw.js、manifest.json、icon.svg、README.md。
5. 等 GitHub Pages 部署成功，测试新图标，检查已有账户、负债和类别图标是否需重新选择。

注意：GitHub 网页不能一键删除整个目录。可先提交新程序与图标，再清理旧文件，以缩短出现破损图片的时间。
