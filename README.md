# 我的记账本（本机保存版）

## 功能
- 日常收入与支出记录：日期、金额、类别、付款方式、备注，可编辑和删除。
- 月度收入、支出、结余统计，以及最近交易列表。
- 负债管理：信用卡、个人借款、个人贷款、汽车贷款、房屋贷款和其他。
- 还款明细、累计已还金额、剩余欠款自动计算；不计算利息。
- JSON 完整备份/恢复、CSV 交易记录导出。
- 响应式手机界面，支持在 HTTPS 网站上添加到主屏幕。

## 重要：数据存储
数据存储在当前浏览器的 localStorage 中，不会自动上传云端。请定期导出 JSON 备份。清除浏览器网站数据、换浏览器或换手机前，请先备份。不要在公共或共用设备上记录敏感财务信息。

## 最简单的打开方式
1. 解压 ZIP 文件。
2. 在电脑上双击 `index.html`，可先试用。
3. 浏览器本机预览适合测试；如需安装到手机主屏幕，需把这些文件发布到支持 HTTPS 的静态网站。

## 手机安装（需要 HTTPS 网站）
1. 将解压后的全部文件上传到你信任的静态网站托管服务，确保 `index.html`、`manifest.json`、`sw.js` 和 `icon.svg` 放在同一目录。
2. 在手机浏览器打开网站网址。
3. Android/Chrome：菜单中选择“安装应用”或“添加到主屏幕”。iPhone/Safari：点分享按钮，再选“加入主屏幕”。
4. 先新增一笔测试记录，确认功能正常；再开始录入正式数据。

## 使用说明
- 收入/支出在“收支记账”页面新增。
- 先在“负债管理”新增负债，再新增对应还款。
- 还款只减少负债余额，不会自动计入日常支出，以避免重复计算。
- 如果还款记录输错，可删除该还款，系统会重新计算剩余欠款。
- 导入 JSON 会覆盖当前浏览器中的数据，导入前请确认已有备份。

## 隐私与限制
这是个人使用的第一版，不含账号登录、云端同步、利息/分期计划、银行连接或自动交易导入。数据只在当前浏览器设备中保存；浏览器隐私模式可能会在关闭后清除数据。请保管好导出的备份文件。
