# 我的记账本 V5.5 — 图标整理升级版

依据「银行.docx」中提供的银行、贷款公司、电子钱包、投资、购物、电信、消费及油站图标，统一整理为 128×128 WebP，存放在 `brand-icons/`。保留 V5.4 全部记账功能。

新增：Pinduoduo、Sunway Super App、Coffee Bean。更新其他文档提供的图标。原有图片路径保持不变。

**安装：** 先从原记账本导出 JSON 备份（不要上传公开 GitHub），再把本 ZIP 解压后的全部文件和 `brand-icons` 文件夹上传到仓库根目录，覆盖同名文件。

**注意：** 图标来自用户提供的文档截图，部分清晰度有限。`brand-icons/` 是文件夹，不要把其中图片散放到仓库根目录。
