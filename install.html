Android 手机安装步骤

  1. 使用 Google Chrome 打开此页面。
  2. 点击上方的 打开 MyMoney。
  3. 点击 Chrome 右上角的 ⋮ 菜单。
  4. 选择 安装应用，或 添加到主屏幕。
  5. 按照手机提示完成安装，然后从主屏幕打开 MyMoney。

菜单名称可能因 Android 手机和 Chrome 版本而不同。若没有安装选项，可先使用网页版本。

使用前请了解

MyMoney 目前主要将记账资料保存在使用者自己的浏览器／设备中。不同手机之间不会自动同步，分享安装链接也不会分享你的账目。

重要：请定期在「设置与备份」中导出完整 JSON 备份，并将备份妥善保存在安全的位置。卸载 App、清除浏览器网站资料或更换手机前，务必先确认备份可用。

MyMoney 为 GitHub Pages 上提供的网页应用（PWA），并非 Google Play 商店安装包。
