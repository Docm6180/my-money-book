数据备份与恢复

JSON 文件会包含收支、负债、还款、账户和转账记录，可用于恢复完整数据。建议定期备份，并把文件保存在安全的位置。

导出交易记录

将收支记录导出为 CSV，可用 Excel 打开。此文件只包含日常收入和支出，不包含负债还款或内部转账记录。

清除本机数据

此操作会删除当前浏览器保存的全部记录（包括账户和转账），且无法撤销。请先备份。

使用提示

  • 只在当前浏览器/设备保存，不会自动同步到其他手机。
  • 换手机、换浏览器或清除浏览数据前，请先下载 JSON 备份。
  • 关联扣款账户的还款会减少负债与账户余额，并计入总览的本月总流出，但不会自动生成普通支出记录。
  • 若要在手机上安装为应用，需要将网页发布到支持 HTTPS 的网站，再用浏览器「添加到主屏幕」。
